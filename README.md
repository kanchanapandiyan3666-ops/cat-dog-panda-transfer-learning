## Cat Dog Panda Image Classification
## Overview
This project uses transfer learning with PyTorch to classify images into three classes: Cat, Dog, and Panda.

## Model
ResNet18 pre-trained model is used for transfer learning.

## Dataset
Cats-Dogs-Pandas Images dataset from Kaggle.

## Technologies
Python
PyTorch
Torchvision
Matplotlib
Scikit-learn
GPU
CUDA is used when a GPU is available.

## Training
The model is trained using the Adam optimizer and CrossEntropyLoss.

## Results
The notebook contains the training results, test accuracy, and confusion matrix.
